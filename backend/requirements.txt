# PINNED SO EVERY PYTHON FROM 3.11 TO 3.14 GETS READY-MADE PACKAGES.
#
# This is not about being current. numpy, pandas, scipy and pydantic-core ship
# as compiled code, built separately for each Python version. If a pin has no
# build for the Python you happen to have, pip does NOT fail -- it downloads the
# source and starts compiling, with no warning and no estimate, for 30-60
# minutes, and then dies. The screen just scrolls.
#
# It happened twice on 2026-09-24:
#   1. numpy 2.2.1 / pandas 2.2.3 stop at Python 3.13. python.org hands new
#      users 3.14. A fresh install compiled for over fifteen minutes.
#   2. Then pydantic-core -- which is NOT listed here, pydantic pulls it in --
#      failed with "the configured Python interpreter version (3.14) is newer
#      than PyO3's maximum supported version (3.13)". It is written in Rust.
#
# The second one is the lesson: a hand-written list of "the compiled ones"
# checks what you thought of. `test_fresh_clone.py` resolves the ENTIRE tree,
# wheels only, for 3.11/3.12/3.13/3.14 on both Mac chips, in about 30 seconds.
# Run it before changing any pin below.
#
# Verified 2026-09-24: 8/8 combinations resolve from wheels; install takes ~30s;
# full suite 540 passed.
