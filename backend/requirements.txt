# PINNED SO THAT EVERY PYTHON FROM 3.11 TO 3.14 GETS A READY-MADE PACKAGE.
#
# This is not about being current. numpy, pandas and scipy ship as compiled
# code, built separately for each Python version. If the pinned version has no
# build for the Python you have, pip does not fail -- it silently downloads the
# source and starts COMPILING, for 30-60 minutes, ending in a scipy failure
# because it needs a Fortran compiler that is not installed. The screen just
# scrolls. Nothing says why.
#
# That is exactly what happened on 2026-09-24: numpy 2.2.1 and pandas 2.2.3
# stop at Python 3.13, python.org hands new users 3.14, and a fresh install sat
# compiling for over fifteen minutes before being killed.
#
# The versions below are the EARLIEST that have prepared packages for all of
# 3.11, 3.12, 3.13 and 3.14, so whichever Python someone happens to have, the
# install takes about half a minute.
#
# Before changing any of the four scientific pins, check the replacement has
# builds for every supported Python. `test_fresh_clone.py` checks this too.
